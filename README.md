# Clawdi Homebrew Tap

Official Homebrew packages for [Clawdi](https://clawdi.ai).

## CLI

```sh
brew install clawdi-ai/tap/clawdi
```

Upgrade with:

```sh
brew upgrade clawdi
```

## Desktop beta

```sh
brew install --cask clawdi-ai/tap/clawdi@beta
```

Clawdi Desktop updates itself on its selected release channel.
